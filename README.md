# Coliving: Su Shi and Stefan Zweig

Live website: https://jasonpipi.github.io/coliving-su-shi-zweig/

An AI-assisted comparative-literature artwork. Two separately trained Word2Vec models support 15 bilingual concepts, frequency-scaled word clouds and an imagined shared room.

Hover a word or object to compare relations and read excerpts. Click to inspect; press Escape to return.

The side maps independently project cosine-derived distances, with a shared display scale and independent axes. Object positions balance bilingual relation profiles with room composition; they are approximate, not exact embedding distances. Counts are original corpus token counts. Illustrations are cultural metaphors.

This repository contains the static website and exported model-derived data. It does not require a server or loading the full training corpora. LXGW WenKai font subset is distributed under the accompanying OFL license.
